e-Xerox 🖨️

Smart Online Xerox Ordering System (College MVP)

Problem

In our college, students waste time standing in long queues at the xerox shop just to submit print files.
The shop handles multiple students, files, and print options manually, which causes delays and confusion.

Solution

e-Xerox allows students to upload documents online, choose print options, and submit print orders digitally.
The xerox shop receives all orders in one dashboard and processes them efficiently.

This reduces waiting time and simplifies print management.

MVP Scope (Very Important)

This project is built as a Minimum Viable Product (MVP).
Only essential features are included.

Student Side

Upload PDF file

Select print options:

Black & White / Color

Single / Double sided

Number of copies

Submit print order

View order status

Xerox Shop Side

View all incoming orders

Open and review files

Print files manually

Update order status

Order Status Flow

Pending → Order received

Printing → Being printed

Ready → Ready for pickup

Students collect prints by showing Order ID.

What is NOT included (for now)

No payments

No login / authentication

No OTP

No auto-printing

No notifications

These features may be added later after MVP validation.

Tech Stack

Frontend: Next.js + Tailwind CSS

Backend: Next.js API Routes

Database (MVP): Temporary / in-memory storage

Version Control: Git & GitHub

Project Goal

Build a simple, reliable system that works in real college conditions.
